# Obol 0.1.0

Obol 0.1.0 is the first local-first desktop release.

## Included

- A daily cash-flow forecast backed by the Obol transaction ledger.
- Structured ledger filters, matching summary totals, lifecycle details, and CSV export.
- A native Electrobun app that starts PocketBase and the Elysia API locally.
- Persistent per-user desktop data, isolated from hosted PocketBase data.
- The existing hosted web mode remains available.

## Platforms

- macOS arm64
- macOS x86_64

## Notes

- Desktop data starts in a new local profile; hosted data is not imported or synchronized.
- The application does not yet include an in-app updater.
- Direct downloads use ad-hoc signing; Homebrew clears the quarantine flag during installation.
