# Obol 0.1.0a

This hotfix adds a Nod-style local profile setup and unlock flow and repairs the PocketBase authentication failure seen after upgrading from 0.1.0.

## Included

- Create a local name, email, and password on first launch; unlock the profile on later launches.
- Store a salted PBKDF2 verifier instead of the plaintext password.
- Reconcile PocketBase's internal superuser credential with `superuser upsert` before starting the local service.
- Preserve existing 0.1.0 PocketBase collections and records during first-time profile setup.

The login gates the app but does not encrypt PocketBase files on disk. Use macOS FileVault to protect local files at rest.
