# Obol 0.2.0

This release brings the dashboard up to a daily-use finance workspace and adds a native Windows x64 desktop package.

## Included

- A monthly calendar previews the projected balance on each forecast day. Selecting a date opens the same balance details as the trajectory chart.
- Clear current-versus-projected balances, quick transaction entry, and shortcuts to the ledger, cards, and management modules.
- Visible transaction-list errors with retry, plus empty states for accounts with no matching activity.
- Windows x64 Electrobun setup package with a pinned, checksum-verified PocketBase binary. macOS arm64 and x86_64 release artifacts remain supported.

Windows setup packages are unsigned and may prompt SmartScreen. macOS packages remain ad-hoc signed, not Developer ID signed or notarized. Obol does not currently update itself.
