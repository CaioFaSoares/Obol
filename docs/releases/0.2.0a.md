# Obol 0.2.0a

This hotfix repairs the PocketBase migrations path in the published 0.2.0 macOS package and adds the Electrobun in-app updater.

## Included

- Bundle PocketBase migrations at the exact path used by the desktop runtime. Existing PocketBase data remains in place.
- Check the stable release channel at startup and download available updates in the background.
- Show update status, progress, and retryable errors. Offer restart-to-install after the update is ready.
- Publish Electrobun update metadata and full bundles for macOS arm64/x86_64 and Windows x64. The Homebrew cask continues to use only the macOS manifest.

The 0.2.0 app has no updater and cannot install this hotfix automatically. Install 0.2.0a manually once; subsequent stable releases can update in-app. Windows setup packages are unsigned and may prompt SmartScreen.
